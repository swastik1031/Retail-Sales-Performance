# 📊 Retail Sales Performance Dashboard

An interactive **Business Intelligence dashboard built with Microsoft Power BI** to analyze retail sales performance, product demand, store performance, customer preferences, and historical revenue trends.

The project transforms raw retail transaction data into **actionable business insights** through data cleaning, DAX-based calculations, interactive slicers, KPI cards, and cross-filtered visualizations.

---

## 📌 Project Overview

Retail businesses generate large volumes of transactional data, but raw data alone does not provide clear insights for decision-making.

This project addresses that problem by developing an interactive **Retail Sales Performance Dashboard** that allows business users to monitor key performance indicators and analyze sales across:

* Store types and locations
* Product categories
* Product-level performance
* Fat-content preferences
* Store sizes
* Store establishment years
* Revenue and item-level sales performance

The dashboard is designed with an **executive dark-theme interface** to provide a clean and intuitive analytical experience.

---

The primary objectives of this project are to:

# 🧹 Data Preparation & ETL

Data preparation was performed using **Power Query Editor**.

### Data Cleaning Steps

#### 1. Standardization of Fat Content

The dataset contained inconsistent representations of the same categories.

Examples:

```text
LF
low fat
Low Fat

reg
Regular
```

These values were standardized into:

```text
Low Fat
Regular
```

---

#### 2. Missing Outlet Size Values

Missing values in the `Outlet_Size` field were handled by introducing:

```text
Unknown
```

This prevented missing categorical values from affecting dashboard filtering and visualization.

---

#### 3. Data Type & Formatting

Additional preparation included:

* Correcting numerical data types
* Formatting sales metrics
* Standardizing categorical fields
* Preparing year fields for analysis
* Ensuring consistent values for dashboard filtering

# 🧮 DAX Measures

The dashboard uses explicit DAX measures for dynamic calculations.

### Total Sales

```DAX
Total Sales = SUM(Sales[Total_Sales])
```

Calculates the total revenue generated by all transactions within the current filter context.

### Average Sales

```DAX
Average Sales = AVERAGE(Sales[Total_Sales])
```

Calculates the average sales value per transaction.

### Total Items Sold

```DAX
Total Items Sold = COUNT(Sales[Item_Identifier])
```

Counts the number of item records contributing to the dashboard.

### Total Stores

```DAX
Total Stores = DISTINCTCOUNT(Sales[Outlet_Identifier])
```

Calculates the number of unique retail outlets.
